# RAG Pipeline

## 触发
- 茶文化知识检索（AI 茶灵）；文化库 embedding/检索优化。

## 工作流
1. 文档来源：现有 `src/data/` + seeds 迁移数据（禁编造，来源可追溯）。
2. 切片策略：按文化单元（茶/人/诗/器）切块，保留元数据（来源/ID）。
3. embedding 入库 + 检索（top-k + 相似度阈值 + 重排可选）。
4. 检索质量评估：命中率/相关性人工抽查；低质 → 调切片/阈值/索引。
5. 答案必须引用来源（禁模型裸答文化事实）。

## 红线
- 不编造茶名/茶器/历史人物（文化纪律）；答案带来源。

## 自检
- [ ] 来源可追溯（切片元数据）
- [ ] 检索质量抽查通过
- [ ] 答案引用来源
- [ ] 无编造内容
