# Stats Report

## 触发
- 统计类查询（品鉴趋势、八维分布、成长曲线）。

## 工作流
1. 聚合查询（COUNT/AVG/GROUP BY）确认索引可用（EXPLAIN）。
2. 大数据量预聚合：物化视图或定时汇总表（配合 scheduled-task）。
3. 时间范围参数化，禁无界全量聚合。
4. 输出 VO 契约稳定（前端 ECharts 消费）。

## 自检
- [ ] 聚合查询 EXPLAIN 通过
- [ ] 无全表聚合（预聚合或分页）
- [ ] 输出契约与前端一致
