# AI Fallback

## 触发
- AI 降级链维护；502 处理；teaAI.ts 承重墙改动。

## 工作流
1. 后端：AI 调用失败/超时 → fallback 策略（规则回复/缓存答案），返回结构化错误（502）。
2. 前端：teaAI.ts 捕获 502 → 降级规则回复（网络不可用时本地规则）。
3. **承重墙回归**：任何改动必须保留降级链 + 跑回归（离线场景测试）。
4. 降级触发告警（指标 + 日志），统计降级率。

## 红线
- 降级链（teaAI.ts）禁删禁削弱（#10）；AI 代理禁直连（#10）。

## 自检
- [ ] 502 触发降级（非崩溃）
- [ ] teaAI.ts 承重墙未动或已回归
- [ ] 降级有告警 + 统计
