# File Upload

## 触发
- 上传场景（用户头像、茶照片）；首版可延后，用到时启用。

## 工作流
1. 校验：大小上限、MIME 白名单、文件类型魔数（禁只信扩展名）。
2. 文件名安全：UUID 重命名，禁用户原始文件名直存（防路径穿越）。
3. 存储路径外置配置；下载接口鉴权（禁未登录直链）。
4. 清理：无效文件定时清理（配合 scheduled-task）。
