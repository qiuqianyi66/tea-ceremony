# CPU High

## 触发
- CPU 使用率高/接口卡顿；无死锁响应。

## 工作流
1. 定位：top/ps 找进程 → `jstack`（多次采样）→ 热点线程（RUNNABLE/锁等待）。
2. 分类：计算密集（优化算法/缓存）、GC 频繁（见 02-oom）、死循环（补边界）、锁竞争（缩小临界区）。
3. 修复：热点优化 + 有界化 + 限流（必要时）。
4. 验证：CPU 曲线回落 + 接口延迟达标。
