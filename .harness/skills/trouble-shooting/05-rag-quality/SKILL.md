# RAG Quality

## 触发
- AI 茶灵回答不相关/无来源/文化事实错误。

## 工作流
1. 复现问题 query → 看检索 top-k 结果（是否命中正确文档）。
2. 定位：切片粒度（过细丢上下文/过粗噪声）、embedding 模型、相似度阈值、索引缺失。
3. 修复：调切片/阈值/重排；补索引；来源元数据补全。
4. 验证：抽查集命中率对比（修复前 vs 后）；答案带来源。

## 红线
- 不编造文化事实（文化纪律）；答案必须引用来源。

## 自检
- [ ] 检索命中率提升（可对比）
- [ ] 答案带来源
- [ ] 无编造内容
