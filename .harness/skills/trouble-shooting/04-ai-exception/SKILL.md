# AI Exception

## 触发
- /api/v1/ai/* 异常：超时、502、内容异常、Schema 校验失败。

## 工作流
1. 分类：超时（调超时/重试）、限流（429 退避/降级）、内容异常（重试/降级）、Schema 校验失败（模型输出问题 → 修 prompt/校验）。
2. 检查降级链：502 → 前端 teaAI.ts 是否正常降级（回归测试）。
3. 检查 token 成本：异常是否导致用量激增（ai_usage_logs 核对）。
4. 修复 + 回归：降级链测试 + 异常路径单测。

## 红线
- 降级链不可删（#10）；AI 请求走后端代理（#10）。

## 确定性入口

- 降级后 AI 质量回归：`node scripts/eval-tea-ai.cjs`（全量 1 次迭代）；`--iterations 3` 跑 pass^3

## 自检
- [ ] 异常分类明确
- [ ] 降级链回归通过
- [ ] token 用量无异常激增
