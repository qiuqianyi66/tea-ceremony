# 技能规范（Skill Governance）

> 技能治理唯一权威。适用 `.agents/skills` 与 `.harness/skills` 全部技能。新增、修改、删除技能前先读本文件。
> 参考 mattpocock/skills 约定（触发式描述、路由表、小而单一职责、用户触发与模型触发区分），按 tea 现状裁剪。

## 1. 目录组织（禁自创路径）

- `.agents/skills/<skill>/SKILL.md`：通用与领域技能，**扁平存放**，目录名 kebab-case，与 frontmatter `name` 同名。
- `.harness/skills/<family>/<NN-name>/SKILL.md`：流程族（main-dev 6 / biz-dev 19 / trouble-shooting 5）。数字前缀与 ADR-011、PRD 9.3 映射，**禁随意改动编号**。
- 全局工作区（`.skills` / `.user_skills`）与项目同名技能允许并存（上下文不同，如 plan-control 两版），差异在路由表标注，**互不覆盖、不互相删除**。
- 同名技能跨栈分工允许：迁移技能双轨——过渡期旧 FastAPI 用 `.agents/skills/db-migration`（Alembic），新 Spring Boot 用 `.harness/skills/biz-dev/09-db-migration`（Flyway），按 AGENTS.md §8 选路，**不视为重复**。
- 技能资源（模板/示例/子库）放技能目录内；设计参考库按 `design-md-collection/brands/<name>/` 惯例。
- 第三方导入包保留其 `license` / `compatibility` / `metadata.author` 归因字段，不删。

## 2. SKILL.md 模板（必填字段）

```markdown
---
name: <与目录同名，kebab-case>
description: <触发式描述，见 §3>
disable-model-invocation: true   # 仅用户手动触发的技能（如 plan-control）；模型可自动触发的省略
---

# <技能名>

## 触发条件
…
## 前置条件（硬门，缺失回退）
…
## 规则 / 流程
…
## 检查清单
…
```

- 正文结构：触发条件 → 前置条件/硬门 → 规则/流程 → 检查清单。
- 引用 `.harness/rules/编码规范.md` 红线编号（如 #8/#10），**禁止重复定义红线内容**。
- 正文只写给模型看；篇幅 ≤ 300 行为宜，超长拆技能（单一职责）。
- 项目规则类技能（tea 专属 / 控制协议）**必须**配 `docs/skills/<skill>.md` 人读审查页：面向人核对，含【它管什么 / 何时该用与不该用 / 审查要点 / 怎么知道它在生效】；导入包技能不配。
- 不写人话开场白（"我会帮你…"）；直接给规则。

## 3. 描述句式（触发式）

- 中文：`<职责一句话>。当用户要求 <触发场景> 时触发。`（例：tea-tasting）
- 英文：沿用导入包的 "Use for… / Load when… / Covers…" 句式，**不强制中文化**。
- 禁止：把正文大纲抄进 description；description 超过 3 句；不含触发场景。
- 控制/流程类技能（plan-control 等）也必须精简为触发式，不贴正文。

## 4. 路由表（README 不列 = 不存在）

- `.agents/skills/README.md`：全部技能按族分组，一行描述 + 链接 SKILL.md。
- `.harness/skills/<family>/README.md`：族内路由表（已存在）。
- 增 / 删 / 改名 / 跨族移动技能：同步全部相关 README + AGENTS.md §13 记一行。
- 路由表一行描述用中文一句话（面向人），不照抄 frontmatter。

## 5. 新增 / 修改 / 删除流程

- **新增**：先检索全局 + 项目是否已存在（禁重复造轮子）→ 按 §2 模板写 → 项目规则类技能建 `docs/skills/` 人读页 → 更新路由表 → AGENTS.md §13 记一行。
- **修改**：按 AGENTS.md §4 AI Change Protocol；L1+ 改动跑对应验证。
- **删除**：先 Read 全文确认无独立价值（AGENTS.md §10）→ 走 git 删除（保留历史）→ 更新路由表。
- 导入新技能包前先过四维甄别（AGENTS.md §13），导入后立即补路由表。

## 6. 审计命令（每次技能增删改后跑）

```powershell
# frontmatter 必填与 name=目录名校验（PowerShell，仓库根目录执行）
Get-ChildItem .agents\skills,.harness\skills -Directory -Recurse | ForEach-Object {
  $f = Join-Path $_.FullName 'SKILL.md'
  if (Test-Path $f) {
    $c = Get-Content $f -Encoding UTF8 -TotalCount 6
    if (-not ($c -match '^name:')) { Write-Output "缺 name: $f" }
    if (-not ($c -match '^description:')) { Write-Output "缺 description: $f" }
    $n = ($c | Select-String '^name:').Line -replace '^name:\s*',''
    # 流程族目录带 NN- 数字前缀（§1，ADR-011 映射，禁改编号）；name 用纯 kebab-case，比对时剥前缀
    $dir = $_.Name -replace '^\d{2}-',''
    if ($n -and $n -ne $dir) { Write-Output "name≠目录: $($_.Name) -> $n" }
  }
}
```

通过标准：无 "缺" 与 "name≠目录" 输出；README 覆盖数与 SKILL.md 数一致。

## 7. 与全局技能的关系

- 豆包工作区全局技能（doubao-*、lark-*、sheet/ppt/word/pdf 等）由平台维护，**项目内不复制**。
- 项目内只放 tea 专属技能与流程技能；通用 Web/Three.js 技能来自导入包，改动前先确认来源与归因。
