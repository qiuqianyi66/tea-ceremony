# 规则 / 技能 / 工具 三层语义

> 2026-10-08 新增（K3，来源：华为 CodeArts 码道官方分层定义 + Trae 官方 token 分工说明，见 `docs/research-harness-domestic-2026-10.md` D2）。
> 本页是 harness 三层的唯一语义说明。AI 开工前按此理解每层文件的加载方式与职责。

## 三层定义

| 层 | 语义 | 加载方式 | 一盏茶落点 |
|---|---|---|---|
| 规则（Rule） | 约束 AI 行为方式的常驻指令 | **全量加载进上下文，持续参与推理** | AGENTS.md、`.harness/rules/*.md` |
| 技能（Skill） | 描述如何完成特定任务的可复用片段 | **按需加载，命中相关任务才注入全文** | `.agents/skills/*/SKILL.md`、`.harness/skills/*/SKILL.md` |
| 工具（Tool） | 外部能力调用（API/脚本/MCP） | **不参与推理，仅被调用时执行** | `src/services/api/`、Spring AI `@Tool`（CultureSearchTool）、scripts/*.cjs |

## 红线（token 分工，禁止违反）

1. 规则=全量常驻，技能=渐进按需加载。禁止把技能内容抄回规则文件。
2. 技能内容膨胀时，收敛技能本身，不许回流 AGENTS.md 或 `.harness/rules/`。
3. 工具不参与推理：调用失败走降级（返回错误标记），不许把工具输出拼进规则。
4. 新增规则先问"这条是常驻约束还是按需能力"。按需能力进技能，不进规则。
