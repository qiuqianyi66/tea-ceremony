# 3D 数字茶空间（夜色暖光）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把冲泡页 CSS 插画视觉替换为 TresJS 3D 真实感茶席，风格定为「夜色暖光·炭火煮茶」，保留现有状态机/手势/音频。

**Architecture:** 用 TresJS（Vue 声明式 Three.js）在 BrewView 背景层渲染 3D 茶席：夜色环境 + 暖光 + 木桌 + 程序化盖碗/茶壶/炉 + 蒸汽粒子 + 炉火 + 茶汤色联动 + 出汤倾斜。视觉由 props（phase/soupColor/temp/isPouringOut）驱动，业务逻辑零改动。

**Tech Stack:** @tresjs/core + three（已装）+ Vue 3 + TypeScript 严格模式

**Spec:** `3D_SPEC.md`（本仓库根目录）

## Global Constraints

- 视觉风格硬约束：夜色暖光·炭火煮茶；真实抓拍感、柔光、胶片颗粒质感；**禁止**"AI 精修大片感/摆拍感"
- 只替换视觉层：状态机（BrewPhase）/ 注水手势 / 按钮 / 音频 / 进度条 全部不动
- 零外部 3D 模型依赖（Sketchfab 需登录不可自动化；茶具程序化建模，PBR 材质）
- type-check / build / E2E（full-journey 5 用例）不回归
- 简体中文注释；遵循 Vue 3 + `<script setup lang="ts">` 项目规范

### Task 4: 蒸汽粒子 + 炉火 + 阶段/数据联动

**Files:**
- Modify: `src/components/three/TeaBrewScene3D.vue`

**Interfaces:**
- Consumes: props `phase` / `currentTemp` / `targetTemp` / `soupColor`
- Produces: 蒸汽 Points（CanvasTexture 软圆点，上飘循环）、`syncPhase/syncSoupColor/syncTemp` 联动逻辑、`useLoop` 每帧更新

- [ ] **Step 1: 蒸汽粒子系统**

60 个粒子从壶口/碗口上飘，速度/顶部限位循环，opacity 随温度与阶段平滑过渡（HEATING 随温度增强，冲泡期 ~0.35，闲置 ~0.1）

- [ ] **Step 2: 火焰脉动 + 炉火光联动**

火焰片 scale 正弦脉动；炉火点光源强度 = min(1, temp/target)；仅 HEATING 显示火焰

- [ ] **Step 3: watch 联动 props**

`phase`/`soupColor`/`currentTemp` 变化 → 更新蒸汽强度、火焰、茶汤色

- [ ] **Step 4: 验证联动**

截图对比 IDLE vs HEATING vs STEEPING 阶段：火焰/蒸汽/茶汤色应随阶段变化。
