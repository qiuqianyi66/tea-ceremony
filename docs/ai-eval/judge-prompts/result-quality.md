# 单维评委模板 — 结果质量（result-quality）

> 用途：LLM-as-Judge 判分 judge 考点（T12，F-A5）。每次只评一个维度，0/1 选择题。
> 复用：过程质量（process-quality）与安全稳定（safety-stability）评委复用本结构，仅替换「评委维度」与「给分要求」两段。

## 评委维度

只评一个维度：AI 茶灵的回答是否满足任务要求（结果质量）。

## 输入

- 考点（point.name）：{point.name}
- 用户输入：{input}
- AI 回答：{output}

## 给分要求

- 回答满足考点 → 输出 1。
- 回答不满足考点 → 输出 0。
- 信息不足（无法判断）→ 输出 UNKNOWN。
- 只输出 0 / 1 / UNKNOWN 三选一，不写评语。

## 位置偏差控制

- 同一批样本按 A/B 两种顺序各评一次；两次结论不同 → 该样本标记「不稳定」，人工复核。
- 每次评测随机抽 10% 样本人工复核，与机评不一致 → 计入校准一致率。

## 输出格式

```text
1
```

## 判分示例

- 考点「茶类归属正确」，回答含正确茶类 → 1
- 考点「茶类归属正确」，回答含错误茶类 → 0
- 考点「引用知识库出处」，回答未提来源且无法核对 → UNKNOWN
