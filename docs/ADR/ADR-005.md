# ADR-005：SQLAlchemy 2.0 异步 + Alembic 迁移

- **Status**: Accepted
- **Migrated**: 2026-10-01（原载于 CONTEXT.md，未改内容）

## Context

异步性能好；迁移可追溯、可回滚。

## Decision

后端用异步 SQLAlchemy，所有 schema 变更走 Alembic。

## Consequences

禁止手动改数据库；模型变更必须生成迁移脚本。

## Rejected

未记录（原 CONTEXT.md 未载明）。
