# ADR-006：本地行为埋点（不远程上报）

- **Status**: Accepted
- **Migrated**: 2026-10-01（原载于 CONTEXT.md，未改内容）

## Context

离线优先是核心特性，埋点不能依赖网络；只存结构化事件（category/event/label/result），不采集用户输入等自由文本，隐私风险最低；2000 条封顶裁剪，防本地膨胀。

## Decision

行为埋点走 IndexedDB（trackingEvents 表）纯本地存储，不接第三方统计、不上报后端。

## Consequences

`src/services/tracking.ts` 白名单校验入参、track 永不 reject；T2.4 茶灵去留按 `getTrackingSummary()` 决策；未来若需远程分析，另行设计导出与用户同意机制。
