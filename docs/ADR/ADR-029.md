# ADR-029：自托管 embedding 通道（onnxruntime + bge-large-zh-v1.5 ONNX）

- **Status**: Accepted（B1.1 向量 RAG 落地；v9 评测 RAG 0.38 → 0.48）
- **Related**: 蓝图 B1.1；`OnnxEmbeddingConfig` / `OnnxEmbeddingModel`；`CultureSearchService.vectorHits`；V9 评测报告 2026-10-30.json

## Context

DashScope 账户欠费（实测 400 Arrearage），远程 embedding（text-embedding-v3）不可用；gateway profile 已排除 DashScopeEmbeddingAutoConfiguration（欠费治理，2026-10-28），检索降级纯 ILIKE，A8 RAG 命中率目标无法达标。需要自托管 embedding 通道恢复向量检索，且不触碰聊天承重墙（ChatModel 仍走 DashScope/gateway）。

## Decision

1. **onnxruntime + bge-large-zh-v1.5 ONNX**（1024 维，MIT，CPU 推理，`D:\models\bge-large-zh-v1.5-onnx`，仓库外禁提交）。1024 维对齐 `culture_chunks.embedding vector(1024)`，**免 schema 迁移**。
2. **装配与降级**：`OnnxEmbeddingConfig` 按 `tea.embedding.onnx.model-path` 配置建 bean，模型文件缺失时不建 bean → 无 EmbeddingModel 候选 → `CultureSearchService.getIfUnique()` 返回 null → 降级纯 ILIKE（承重墙不变，可观测日志 no_model）。bean 标记 `@Primary`（getIfAvailable 场景多 bean 时优先自托管）。
3. **排除远程 embedding 自动配置**：main + test 配置均排除 `DashScopeEmbeddingAutoConfiguration`——dashscope starter 在 key disabled 时仍装配 bean（实测），若与 onnx 并存则 `getIfUnique` 返回 null → 生产向量检索假失效；且欠费账户每次检索多一次失败付费调用。排除后自托管是生产唯一 EmbeddingModel。
4. **检索侧 BAAI 官方 query instruction 前缀**：`embedQuery()` 对 query 加「为这个句子生成表示以用于检索相关文章：」前缀（passage 侧不带），对齐 bge 系列官方检索用法。
5. **onnxruntime 版本 = 1.20.0**（Java 8+ 兼容稳定版；开发中曾试 1.31.1 最新版，回退 1.20.0 保最大兼容；Maven 依赖以 pom 为准）。
6. **部署配套**：Dockerfile 用 glibc 基础镜像（temurin-21-jre）+ `libstdc++6`（onnxruntime JNI 依赖）；docker-compose 注入 `TEA_EMBEDDING_ONNX_MODEL_PATH` + 模型卷挂载。

## Consequences

- v9 评测：RAG 0.38 → **0.48**（recall@k + citationRate 指标），DashScope 欠费不再阻塞向量通道。
- 评测/测试环境单 onnx bean（排除 dashscope embedding），`getIfUnique` 确定性命中；集成测试需模型文件（CI 无模型自动 skip，本机真跑）。
- 风险：模型文件丢失 → 检索静默降级纯 ILIKE（有日志）；bge-large 比 small 推理重（CPU 场景），若需提速再评估量化/换 small（代价 L3 迁移）。
- 反转条件：DashScope 恢复付费且远程 embedding 质量/成本更优时，改回远程通道（改排除列表 + 配置键，代码零改动）。

## Rejected

- **bge-small-zh-v1.5**（512 维）：需 L3 迁移（ALTER vector(512) + 重建 HNSW + 全量重嵌），代价大、收益未证（蓝图 D1 已评估）。
- **bge-m3**：1024 维免迁移但模型更大、CPU 推理更重，社区 ONNX 导出成熟度不如 bge-large-zh-v1.5。
- **远程 DashScope embedding**：欠费不可用（实测 400 Arrearage），且每次检索多一次失败付费调用。
