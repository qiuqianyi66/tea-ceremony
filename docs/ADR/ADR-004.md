# ADR-004：前后端分离 + Nginx 代理

- **Status**: Accepted
- **Migrated**: 2026-10-01（原载于 CONTEXT.md，未改内容）

## Context

部署简单，前后端独立开发，安全头统一在 Nginx 配置。

## Decision

前端 Vue SPA，后端 FastAPI，Nginx 做 SPA fallback 和 API 代理。

## Consequences

API 路径统一前缀 `/api`；前端开发环境代理到 `localhost:8000`。
