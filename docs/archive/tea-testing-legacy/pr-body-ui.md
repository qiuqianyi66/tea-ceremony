## 概述

冲泡页 UI 升级为方向 A：毛玻璃深色面板 + 琥珀描边 + 发光温度，与 3D 夜色暖光茶席背景形成统一视觉风格。

## 核心改动

### 视觉系统
- **深色毛玻璃主题**：冲泡页覆盖全局 CSS 变量，文字改为浅琥珀色，面板改为深棕色半透明
- **毛玻璃面板**：`rgba(26,18,12,0.72)` 背景 + 16px 高斯模糊 + 饱和度增强 + 琥珀色描边 + 内发光阴影
- **发光温度**：温度/时间大数字使用琥珀色双层 text-shadow 光晕效果，数字等宽对齐
- **琥珀描边按钮**：主按钮和茶器卡片使用半透明琥珀描边，hover 时发光增强

### 进度条
- 工夫茶仪式进度条：深色圆点 + 琥珀描边，激活态使用琥珀渐变 + 发光，完成态半透明琥珀
- 连接线：未完成深色，完成后琥珀渐变

### 交互控件
- 温度滑块：深色轨道 + 琥珀渐变滑块 + 发光效果
- 茶器选择卡片：深色半透明背景 + 琥珀描边 hover
- 茶汤色展示卡片：深色毛玻璃 + 琥珀描边

### 范围控制
- 仅作用于冲泡页（scoped style + `.brew-dark` 容器类）
- 不影响首页、选茶页、品鉴页等其他页面
- 3D 场景和 CSS 回退场景均适用
