## 背景

旧首页用大量 CSS 手绘室内茶室（墙面/窗/地板/SVG 茶壶茶杯）+ 2.5 秒黑屏开场 + 7 个并排导航按钮，视觉小气、开场拖沓、导航杂乱，「一点开就没有往下走的欲望」。本次按「5 分钟数字茶歇」定位，把首页改造为沉浸式晨雾茶山，并顺手精简主流程入口。

## 改动内容

### 1. 首页重做为沉浸式晨雾茶山（`src/views/HomeView.vue`）
- **真实摄影背景**：采用 Wikimedia Commons 实景茶山照片（大吉岭茶园，CC BY-SA 4.0），替代原 CSS 手绘场景；Ken Burns 缓慢推近 + 鼠标视差。
- **晨雾氛围**：两层流动薄雾 + screen 混合全局雾层，柔化天空与远山；叠加胶片颗粒，贴合自然写实质感。
- **极简内容**：节气标签 / 品牌名 / 一句定位语 / 随机茶语 / 单个「入席」按钮，居中偏下落在底部压暗区，保证可读性。
- **导航收纳**：顶部只留品牌与一个汉堡按钮，其余入口（选茶、茶地图、茶柜、茶修、茶灵、图谱、登录）收进右侧毛玻璃抽屉，支持遮罩点击与 Esc 关闭、打开时锁定背景滚动。
- **去掉黑屏开场**：内容直接淡入，不再等待 2.5 秒。
- 保留节气、氛围音频、登录态、分时段色温等既有逻辑，并适配 `prefers-reduced-motion` 与移动端。

### 2. 精简主流程入口
- 首页「入席」由 `首页 → /tearoom（十二境文字翻页）→ /select` 改为**直达 `/select` 选茶页**，去掉冗余中转，主流程更连贯。
- 同步更新 E2E `full-journey.spec.ts`：删除十二境中转步骤并顺延步骤编号。

### 3. 修复节气跨年判断 bug（`src/data/solarTerms.ts`）
- 旧实现倒序遍历，9 月会因 `9 > 1` 直接命中 1 月的「大寒」。
- 改为按「立春起、大寒止」的节气年把 1 月折算到 12 月之后，正序取最后一个已到来的节气；修复后 9/5 正确显示「立秋」。

### 4. 素材合规
- `src/assets/tea-mountain-hero.jpg`：作者 Tanmoy281，CC BY-SA 4.0，README 新增「素材致谢」章节注明来源、授权与修改方式。
