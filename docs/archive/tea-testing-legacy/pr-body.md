## 概述

修正泡茶流程不符合传统功夫茶的问题：盖碗出汤应先倒进公道杯（茶海）均匀茶汤浓度，再从公道杯分到品茗杯。

## 核心修正

### 问题
- 原实现：盖碗倾斜 → 茶汤直接倒进品茗杯（浓度不均、茶叶继续浸泡变苦）
- 真实流程：盖碗 → 公道杯 → 品茗杯×3

### 改动
1. **新增公道杯**（玻璃材质，带壶嘴+把手+液面）
   - 出汤时茶汤流入公道杯，液面上升
   - 分茶时公道杯倾斜，液面下降
2. **品茗杯从1个改为3个**，公道杯前方一字排开
3. **重新布局**：盖碗居中偏左（主泡器）、公道杯在盖碗右前方、品茗杯×3在公道杯前方
4. **扩展动画状态机**：新增 fairnessPour（分茶）阶段
   - pourOut：盖碗→公道杯出汤
   - fairnessPour：公道杯→品茗杯分茶
   - drink：分茶完成70%后才触发喝茶（先分茶再喝茶）
5. **双水流系统**：出汤水流（盖碗→公道杯）+ 分茶水流（公道杯→品茗杯）

## 茶文化依据
- 公道杯（茶海/匀杯）核心作用：均匀茶汤浓度、控制浸泡时间避免苦涩、沉淀茶渣
- 传统功夫茶常用3个品茗杯，"茶倒七分满，留下三分是人情"
- 盖碗为"三才碗"（天盖之、人育之、地载之），居中为主泡器
